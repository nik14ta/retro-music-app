# 📻 90s Retro Cinematic Music Player

A beautiful, highly interactive web-based music player designed with a deep nostalgia for the 1990s Indian aesthetic. It features a completely dynamic cinematic UI that reacts to music playback, blending modern web technologies with vintage visual charm.

## ✨ Features

- **Cinematic Transitions:** The background dynamically and gracefully crossfades between two photorealistic 35mm film states (awake and listening) when music is played or paused.
- **Interactive Skeuomorphic UI:** Features a fully animated cassette player with spinning reels, a clickable vintage waveform progress bar, and classic tactile playback controls. 
- **Dynamic Environment:** Immersive environmental effects including a slow Ken Burns camera pan, floating dust motes drifting in the sunlight, rising glowing music notes (`♪`, `♫`) synced to playback, and a subtle film grain overlay.
- **Live Clock & Branding:** Features a real-time live clock and pulsing radio station branding.
- **Custom Playlist:** Built-in playlist support with dynamic song titles, artist names, and active track equalizer animations.

## 🚀 Technologies Used
- **React.js** (Vite)
- **Vanilla CSS3** (Custom Animations, Keyframes, Flexbox layouts)
- **HTML5 Audio API**

## 💿 Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Add your favorite 90s MP3 tracks to the `public/` folder and update the `src/songs.js` file to customize your playlist!

## 📸 Aesthetic Notes
The visual design pays homage to the golden era of 90s Bollywood cassettes, featuring rich sepia tones, warm amber radio lighting, and classic movie posters (like *DDLJ* and *Lamhe*) embedded perfectly into a nostalgic study room environment.
